## 학습 목표

1. UI 셰이더 파일의 세 덩어리(Properties · 공통 include · `frag`)를 찾고, 새 셰이더를 만들 때 **세 군데만** 바꾸면 된다는 것을 설명할 수 있다.
2. `UIShaderEffect` 가 머티리얼을 **인스턴스로 복제**하는 까닭과, 그래서 플레이 중 머티리얼 에셋을 고쳐도 화면이 안 바뀌는 까닭을 말할 수 있다.
3. "계속 반복 = 셰이더 `_Time`, 이벤트 = DOTween 이 프로퍼티 트윈, 매 프레임 외부 값 = `SetVector`" 역할 나누기를 7개 예제에서 구분할 수 있다.

## 개념 설명

### 1. 용어

| 용어 | 한 줄 풀이 |
|---|---|
| 셰이더 (Shader) | 픽셀 하나하나의 색을 GPU 에서 계산하는 프로그램. 여기서는 HLSL(CG) 로 쓴다 |
| 머티리얼 (Material) | 셰이더 + 그 셰이더에 넣을 값(색·숫자·텍스처)을 담은 에셋 (`.mat`) |
| 프로퍼티 (Property) | 머티리얼 인스펙터에 보이는 칸. 코드 이름은 `_` 로 시작 (`_Saturation`) |
| uv (`i.texcoord`) | 이미지 안 위치. 왼쪽 아래 (0,0) ~ 오른쪽 위 (1,1) |
| 프래그먼트 함수 (`frag`) | 픽셀마다 한 번 불려 그 픽셀 색을 돌려주는 함수 |
| 알파 (alpha) | 투명도. 0 = 투명, 1 = 불투명 |
| `_Time.y` | 셰이더 안 경과 시간(초). 반복 애니메이션에 쓴다 |
| 인스턴스 (Instance) | 에셋을 복사해 만든 사본. 사본을 바꿔도 원본은 그대로 |
| SDF | Signed Distance Field. "외곽선까지 거리" 를 담은 값. 0.5 = 경계 |

### 2. 셰이더 파일의 구조 — `UIBase.shader`

[그림: UIBase.shader 를 세 색으로 칠한 그림. ① Properties(5–21) ② SubShader 설정(23–48: Tags·Stencil·Blend) ③ Pass 안 include + 변수 + frag(54–75)]

| 덩어리 | 줄 | 하는 일 |
|---|---|---|
| `Shader "UIEffects/UIBase"` | 1 | 셰이더 이름. 머티리얼 **Shader** 드롭다운에 보이는 이름 |
| `Properties { … }` | 5–21 | 인스펙터 칸. `_MainTex`·`_Color` + 효과 칸(`[Header(Base Adjust)]`) + Stencil 숨김 칸 |
| Tags · Stencil · Blend | 25–48 | UI 는 투명(`Queue=Transparent`), `Mask` 지원(Stencil), 알파 섞기 |
| `#pragma` | 55–59 | 정점 함수는 공통 `UIVert`, 픽셀 함수는 `frag`. RectMask2D·알파 클립 스위치 |
| `#include "UIEffectsCommon.cginc"` | 61 | 공통 함수 가져오기 |
| 변수 + `frag` | 63–74 | 효과 본체 |

`UIBase.shader` 63–74행

```c
float _Saturation;
float _Brightness;

fixed4 frag(v2f_ui i) : SV_Target
{
    fixed4 c = SampleUI(i.texcoord) * i.color;     // 이미지 색 × Image 의 Color

    float g = Gray(c.rgb);                         // 밝기 (흑백 값)
    c.rgb = lerp(g.xxx, c.rgb, _Saturation) * _Brightness;

    return UIFinalize(c, i);                       // 마지막에 항상 호출 (클리핑)
}
```

- `lerp(a, b, t)` = a 와 b 를 t 만큼 섞기. `_Saturation` 0 = 흑백, 1 = 원래, 1.4 = 더 진함.
- Properties 의 이름과 변수 이름이 **같아야** 값이 들어갑니다 (`_Saturation` ↔ `float _Saturation;`).

**새 셰이더는 세 군데만** (`docs/shader-architecture.md`): ① 1행 셰이더 이름 ② Properties 의 `[Header(…)]` 부분 ③ include 아래 변수 + `frag`. 실습 3에서 그대로 합니다.

**꼭 지켜야 할 것** (`docs/shader-architecture.md`)

| 규칙 | 까닭 |
|---|---|
| `_Color` 프로퍼티 유지 | 없으면 기본값 0 이 들어가서 UI 가 투명해짐 |
| Stencil 블록 + 숨김 프로퍼티 유지 | `Mask` 컴포넌트 지원 |
| `UNITY_UI_CLIP_RECT` + `UIFinalize()` | `RectMask2D` 지원 |
| 머티리얼은 인스턴스로 복제 | 같은 에셋을 쓰는 다른 UI·에셋 파일이 같이 바뀌는 것 방지 |
| 이미지는 Image Type = **Simple** | 대부분 효과가 `texcoord` 를 이미지 기준 0~1 로 가정 |
| 스프라이트 Mesh Type = **Full Rect** | Tight 이면 투명 여백이 잘려 글로우·아웃라인이 그려질 공간이 사라짐 |

### 4. 머티리얼 인스턴스 — `UIShaderEffect.cs`

`UIShaderEffect.cs` 17–29행

```csharp
protected virtual void Awake()
{
    if (targetGraphic == null) targetGraphic = GetComponent<Graphic>();
    material = CreateMaterialInstance();
}

protected virtual Material CreateMaterialInstance()
{
    Material source = targetGraphic.material;
    var instance = new Material(source) { name = source.name + " (Instance)" };
    targetGraphic.material = instance;
    return instance;
}
```

- 29~45번 제어 스크립트는 모두 이 클래스를 상속합니다(46번 스켈레톤은 예외, 아래 9절).
- 플레이 중 Image 의 머티리얼은 `Shimmer (Instance)` 같은 **사본**입니다. `Assets/04_Materials/UI/Shimmer.mat` 을 고쳐도 지금 화면은 안 바뀝니다. 실습 2에서 확인합니다.
- 셰이더 값은 DOTween 의 `material.DOFloat(목표, "_Prop", 시간)` 으로 트윈합니다. Ease·Loop·Sequence 를 그대로 씁니다.

**`UIShaderPropertyTween`** (0601 데모가 이것): 인스펙터에 프로퍼티 이름·from·to·시간·Ease 를 적으면 바로 움직여 봅니다. `loop` 를 켜면 Yoyo 무한, 끄면 `Toggle()` 로 왕복. "새 셰이더를 만들었을 때 스크립트를 짜기 전에 이 컴포넌트로 바로 값을 움직여 볼 수 있어요" (`docs/shader/29-shader-base.md`).

### 6. 빛 띠 — 0602 셔이머, 0607 스켈레톤

`Shimmer.shader` 78–86행

```c
// 빛줄기 방향으로 uv 를 투영 → 0(시작)~1(끝)
float pos = ProjectUV(i.texcoord, AngleToDir(_ShineAngle));

// 빛줄기 폭만큼 바깥에서 시작/끝나야 깔끔하게 들어오고 빠져나감
float center = lerp(-_ShineWidth, 1.0 + _ShineWidth, _ShineLocation);
float band = 1.0 - smoothstep(_ShineWidth * (1.0 - _ShineSoftness), _ShineWidth, abs(pos - center));

// 알파는 그대로 두고 색만 더해서, 이미지가 있는 곳에만 빛이 보임
c.rgb += _ShineColor.rgb * _ShineColor.a * band * _ShineIntensity;
```

[그림: 사각 이미지 위 30° 기울어진 띠. ProjectUV 가 띠 진행 방향으로 0(왼쪽 아래 모서리)~1(오른쪽 위 모서리)을 매김]

- `smoothstep(a, b, x)` = x 가 a 이하면 0, b 이상이면 1, 사이는 부드럽게.
- **rgb 에만 더한다** → 별 밖 투명한 곳(알파 0)은 빛이 있어도 안 보입니다.
- 셰이더는 **위치만** 받습니다. 언제·얼마나 빠르게·몇 번은 `ShimmerEffect.cs` 가 정합니다 (26–30행: 0 → `DOFloat(1f, …, 0.8f)` → `AppendInterval(1.5f)` → `SetLoops(-1)`).

| 프로퍼티 | 기본값 | 하는 일 |
|---|---|---|
| `_ShineLocation` | 0 | 띠 위치 (스크립트가 0→1) |
| `_ShineWidth` | 0.15 (데모 0.08) | 띠 폭 |
| `_ShineSoftness` | 0.7 | 가장자리 부드러움 |
| `_ShineAngle` | 30 | 각도 |
| `_ShineIntensity` | 1 (데모 0.7) | 밝기 |

**0607 스켈레톤은 uv 가 아니라 캔버스 좌표** (`SkeletonLoading.shader` 80–86행)

```c
float x = i.worldPosition.x + i.worldPosition.y * tan(radians(_Angle));
float center = lerp(_SweepMin, _SweepMax, frac(_Time.y * _Speed));   // -1200 ~ 1200, 초당 0.7번
float band = exp(-pow((x - center) / _BandWidth, 2.0));               // 폭 220 의 종 모양 띠
```

- 자리표시자 6개가 **머티리얼 하나를 공유**해도, 띠 위치가 화면(캔버스) 기준이라 한 줄로 이어 지나갑니다.
- 시간 기반이라 인스턴스가 필요 없어서 `SkeletonLoading.cs` 는 `UIShaderEffect` 를 상속하지 않습니다. 실제 내용은 `SetDelay(i * itemStagger)`(0.08초)로 하나씩, 30 아래에서 올라옵니다 (57행).

### 7. 모양 따라 빛 — 0603 글로우 vs 0606 아웃라인

[그림: 별 아이콘 한 픽셀 둘레 16방향 점. 왼쪽 "평균 → 번진 실루엣(글로우)", 오른쪽 "최대 − 원본 → 테두리 띠(아웃라인)"]

| | 0603 `GlowPulse.shader` 81–101행 | 0606 `IconOutlinePulse.shader` 83–100행 |
|---|---|---|
| 둘레 읽기 | 16방향 × 2링 = 32번 | 16방향 × 1링 = 16번 |
| 모으는 법 | `sum += …` → **평균** (`sum / 32.0 * 1.6`) | `maxA = max(maxA, …)` → **최대** |
| 결과 | 부드럽게 번진 실루엣 | 딱 떨어지는 팽창 실루엣 − 원본 = **테두리만** |
| 맥박 | 밝기 `lerp(_PulseMin, 1, sin(_Time.y * _PulseSpeed)*0.5+0.5)` | 두께 `_OutlineWidth * (1 + pulse * _PulseAmount)` |
| 합치기 | `BlendOver(c, glow)` — 원본 뒤에 깔기 | `BlendOver(c, o)` |
| 이벤트 | `Boost()`: 3.5 로 세팅 → 1.5 로 0.6초 + 펀치 | `ToggleSelect()`: `_OutlineAlpha` 0↔1 0.25초 + 선택 시 펀치 |

`IconOutlinePulse.shader` 86–94행

```c
for (int k = 0; k < 16; k++)
{
    float a = k * 6.2831853 / 16.0;                       // 360° 를 16등분
    float2 suv = uv + float2(cos(a), sin(a)) * width;
    maxA = max(maxA, tex2D(_MainTex, suv).a * InsideUV(suv));
}
// 팽창 실루엣 - 원본 = 외곽선
float outline = saturate(maxA - tex.a);
```

> 두 효과 모두 그림 **바깥**에 그립니다. 스프라이트 안에 **투명 여백**이 있어야 하고, Mesh Type = **Full Rect** 여야 합니다 (`docs/shader/31-glow-pulse.md`). 빌더가 만든 `StarIcon.png` 등은 이미 그렇게 저장됩니다 (`docs/scene-builder.md`).

### 8. 홀로그램 카드 — 0604 · 선택

`HolographicGradient.shader` 89–111행의 네 겹

| 겹 | 코드 (찾을 글자) | 쉬운 말 |
|---|---|---|
| 무지개 | `HueToRGB(frac(phase))` | uv.x + uv.y + 시간 + 기울기로 색상환을 돈다 → 대각선으로 흐름 |
| Screen 섞기 | `1.0 - (1.0 - c.rgb) * (1.0 - rainbow * _HoloStrength)` | 원래 그림을 살리며 밝게 얹기 |
| 스트라이프 | `sin((uv.x - uv.y) * 60.0 …)` | 가는 사선 줄무늬 |
| 글레어 | `exp(-pow(g / _GlareWidth, 2.0))` | 기울기 따라 움직이는 대각선 빛 |
| 반짝이 | `floor(uv * _SparkleDensity)` + `Hash21(cell)` + `step(0.92, rnd)` | 28×28 칸 중 8% 만 골라 동그랗게 반짝 |

스크립트(`HolographicCard.cs` 42–52행)는 `Update()` 에서 마우스 위치(-1~1)를 `Lerp` 로 따라가 `material.SetVector("_Tilt", tilt)` 로 넘기고, 같은 값으로 카드 `localRotation` 도 돌립니다. 들어오고 나갈 때 크기(1.05)만 DOTween 입니다.

### 9. 텍스트 셰이더 — 0605 · 선택

TMP 글자는 **SDF 폰트 아틀라스**로 그립니다. 29번 템플릿을 그대로 쓰면 글자가 네모 박스로 보여서, 이 셰이더는 SDF 를 직접 읽습니다 (`docs/shader/44-text-gradient-shine.md`).

`TextGradientShine.shader` 96–107행

```c
float d = tex2D(_MainTex, i.texcoord).a + _Dilate;          // 아틀라스 알파 = 외곽선까지 거리
float w = max(fwidth(d), 1e-4) * (0.75 + _Softness * 4.0);  // 화면 1픽셀 폭
float alpha = smoothstep(0.5 - w, 0.5 + w, d);              // 0.5 를 기준으로 잘라 글자 모양

// 텍스트 영역 기준 0~1 위치 (글자마다가 아니라 문장 전체)
float tx = saturate((i.worldPosition.x - _TextRect.x) / max(_TextRect.z, 1e-3));
float ty = saturate((i.worldPosition.y - _TextRect.y) / max(_TextRect.w, 1e-3));
float g = frac(tx * 0.5 + ty * 0.15 - _Time.y * _GradientSpeed) * 3.0;
```

- uv 로 칠하면 글자마다 따로 칠해집니다. 그래서 **캔버스 좌표(`worldPosition`)를 문장 영역(`_TextRect`)으로 나눠** 문장 전체에 한 그라디언트를 겁니다.
- `TextGradientShine.cs` `LateUpdate()`(33–45행)가 매 프레임 `textBounds` 를 캔버스 좌표로 바꿔 `_TextRect` 를 넣습니다.
- TMP 는 `Graphic.material` 이 아니라 `fontMaterial` 로 인스턴스를 만들어야 해서 `CreateMaterialInstance()` 를 바꿔 씁니다 (21–26행).

> ⚠️ 머티리얼 `_MainTex` 에 **폰트 아틀라스**를 꼭 지정해야 합니다. 아틀라스가 다르면 TMP 가 머티리얼을 무시하고 기본 머티리얼로 되돌립니다. Bold 는 이 셰이더에서 안 먹으니, 굵게 하려면 `_Dilate` 를 올립니다 (데모 0.04).

## 정리

- UI 셰이더 = Properties + (Tags·Stencil·Blend) + `UIEffectsCommon.cginc` include + **변수 + `frag`**. 새 셰이더는 이름·Header·frag **세 군데만** 바꾼다.
- `_Color`, Stencil, `UIFinalize()` 는 **지우지 않는다**. 지우면 UI 가 투명해지거나 Mask·RectMask2D 가 안 먹는다.
- 제어 스크립트는 `UIShaderEffect` 상속 → 머티리얼 **사본**을 `material.DOFloat` 로 트윈. 플레이 중 에셋을 고쳐도 화면은 안 바뀐다.
- 반복 = `_Time`(셰이더), 이벤트 = DOTween, 매 프레임 외부 값 = `SetVector`.
- 주변 16방향을 읽어 **평균**이면 글로우, **최대 − 원본**이면 아웃라인. 그림 둘레에 투명 여백 + Full Rect.
- 여러 UI 에 걸쳐 이어지는 효과(스켈레톤 띠, 문장 그라디언트)는 uv 가 아니라 **캔버스 좌표 `worldPosition`**.

## 과제

**과제 1. `FlashTint` 완성** — 실습 3 을 끝내고, `HeartIcon` 스프라이트에도 붙여 하트가 빨갛게 번쩍이게(`_FlashColor` 빨강) 한다.

**과제 2. 셔이머 두 색** — `Shimmer.shader` 에 `_ShineColor2` 를 더해, 띠 가운데는 `_ShineColor`, 가장자리는 `_ShineColor2` 가 되게 한다.

- 변수: `fixed4 _ShineColor2;`

## 확인 질문

1. 커스텀 UI 셰이더에서 `_Color` 프로퍼티를 지우면 어떻게 되는가?
   - **정답**: 기본값 0 이 들어가 `i.color` 가 0 이 되므로 UI 가 투명해진다 (`docs/shader-architecture.md`).
2. 30번 플레이 중 `Shimmer.mat` 의 각도를 바꿨는데 화면이 그대로다. 왜인가?
   - **정답**: `UIShaderEffect.Awake()` 가 머티리얼을 `new Material(source)` 로 복제해 Image 에 넣었다. 화면은 사본(`Shimmer (Instance)`)을 그리므로 원본 에셋을 바꿔도 안 바뀐다.
3. 46번 스켈레톤은 자리표시자 6개가 머티리얼 하나를 같이 쓰는데도 띠가 한 줄로 이어진다. 30번 셔이머처럼 uv 로 계산했다면 어떻게 보였을까?
   - **정답**: uv 는 이미지마다 0~1 이라 자리표시자마다 띠가 따로 같은 자리를 지나 동시에 반짝였을 것이다. 캔버스 좌표(`worldPosition.x`)로 계산해서 화면 전체 기준 한 줄로 지나간다.
