## 학습 목표

1. "프로퍼티 하나(0~1)를 DOTween 으로 밀면 셰이더가 픽셀마다 보일지·안 보일지를 정한다" 는 전환 셰이더의 공통 모양을 5개 예제에서 찾을 수 있다.
2. 임계값(threshold)·`smoothstep`·셀 스냅(`floor`)·원 거리(`length`)·방향 투영(`ProjectUV`) 다섯 가지 계산을 쉬운 말로 설명할 수 있다.
3. "가장 안 보이는 순간에 바꾸기" (`AppendCallback`) 와 "애니메이션 → 셰이더 → 애니메이션" 시퀀스로 새 전환을 만들 수 있다.

## 개념 설명

### 1. 용어

| 용어 | 한 줄 풀이 |
|---|---|
| 임계값 (Threshold) | "이 값보다 작으면 지운다" 의 기준선 |
| 노이즈 (Noise) | 위치마다 0~1 사이로 들쭉날쭉하지만 부드럽게 이어지는 값. `Fbm` 은 노이즈를 여러 겹 겹친 것 |
| `smoothstep(a, b, x)` | x 가 a 이하면 0, b 이상이면 1, 사이는 부드럽게. 경계를 칼같이 자르지 않게 |
| `floor(x)` | 소수점 아래 버리기. 2.7 → 2. 칸(셀) 번호를 구할 때 |
| `length(p)` | 원점에서의 거리. 원을 그릴 때 |
| 가로세로 비율 (`_Aspect`) | 폭 ÷ 높이. uv 는 가로·세로 모두 0~1 이라 긴 이미지에서 원이 찌그러지는 것을 고친다 |
| `fwidth(x)` | 옆 픽셀과 값이 얼마나 다른지. "1픽셀 폭" 을 구해 테두리를 부드럽게 |
| `AppendCallback` | 시퀀스 중간에 함수 한 번 부르기 |

### 2. 전환 셰이더의 공통 모양

| 용어 | 미는 프로퍼티 (0 → 1) | 셰이더가 하는 일 | 스크립트 시간 · Ease |
|---|---|---|---|
| 0701 | `_DissolveAmount` 보임 → 사라짐 | 노이즈 < 임계값 인 곳 지우기 | 1.2초 · `InOutSine` |
| 0702 | `_Progress` 선명 → 가장 거침 | uv 를 칸 단위로 스냅 | 0.4 + 0.4초 · `InQuad` / `OutQuad` |
| 0703 | `_Reveal` 잠김 → 해금 | 원 안쪽만 원래 색 | 1.2초 · `OutCubic` |
| 0704 | `_Fill` 수위 | 물결 수면 아래만 액체 | 1.0초 · `OutCubic` |
| 0705 | `_Progress` 숨김 → 보임 | 방향 위치 < 진행 인 곳만 보이기 | 0.9초 · `InOutSine` |

스크립트 쪽은 거의 한 줄입니다. 예: `DissolveEffect.cs` 22행 `material.DOFloat(1f, DissolveAmount, duration).SetEase(ease);`

### 3. 디졸브 — 임계값 (0701)

`Dissolve.shader` 76–88행

```c
float n = Fbm(i.texcoord * _NoiseScale);                     // 픽셀마다 노이즈 0~1

// 엣지 폭만큼 범위를 늘려서 1 일 때 엣지까지 완전히 사라지게 함
float threshold = _DissolveAmount * (1.0 + _EdgeWidth);

// 임계값보다 노이즈가 작은 곳은 사라짐
float visible = smoothstep(threshold - 0.01, threshold + 0.01, n);

// 임계값 바로 위쪽 띠 = 타는 엣지
float edge = (1.0 - smoothstep(threshold, threshold + _EdgeWidth, n)) * saturate(_DissolveAmount * 20.0);

c.rgb = lerp(c.rgb, _EdgeColor.rgb * _EdgeIntensity, edge);
c.a *= visible;
```

[그림: 가로 노이즈 값 0~1 막대. 임계값 선 왼쪽 = 지움, 선 바로 오른쪽 _EdgeWidth 폭 = 주황 엣지, 그 오른쪽 = 원래 그림. 임계값이 오른쪽으로 움직임]

- 임계값을 0 → 1 로 올리면 **노이즈가 낮은 곳부터** 지워집니다 → 타들어가는 모양.
- 그냥 `_DissolveAmount` 를 쓰면 1 일 때 엣지 띠(1 ~ 1+0.08)가 남습니다. 그래서 `* (1 + _EdgeWidth)` 로 범위를 늘렸습니다.
- `saturate(_DissolveAmount * 20.0)` — 0 일 때는 엣지를 끕니다 (안 그러면 노이즈가 아주 낮은 점이 주황으로 보임).
- 노이즈 텍스처 없이 공통 include 의 `Fbm()` 으로 만듭니다.

| 프로퍼티 | 기본값 | 하는 일 |
|---|---|---|
| `_DissolveAmount` | 0 | 0 보임, 1 사라짐 |
| `_NoiseScale` | 6 | 클수록 잘게 |
| `_EdgeWidth` | 0.08 | 엣지 폭 |
| `_EdgeColor` / `_EdgeIntensity` | 주황 (1, 0.5, 0.1) HDR / 1.6 | 엣지 색 / 밝기 |

### 4. 픽셀화 — 칸 스냅 (0702)

`PixelateTransition.shader` 72–77행

```c
// 초반에 빠르게 거칠어지도록 sqrt 커브 사용
float cells = lerp(_MaxCells, _MinCells, sqrt(_Progress));   // 300 → 6
float2 cellCount = float2(cells * _Aspect, cells);

// uv 를 셀 중심으로 스냅
float2 pixelUV = (floor(i.texcoord * cellCount) + 0.5) / cellCount;
float2 uv = lerp(i.texcoord, pixelUV, step(0.001, _Progress));
```

- `floor(uv * 칸 수)` = 몇 번째 칸인지. `+ 0.5` 해서 다시 나누면 **그 칸의 가운데** uv. 칸 안 모든 픽셀이 같은 색을 읽습니다.
- `sqrt` 커브: `_Progress` 0.25 에서 이미 반쯤 거칠어집니다 → 초반에 빨리 거칠어짐.
- `_Aspect` 를 곱해 칸을 **정사각형**으로. 스크립트가 `ApplyAspect()` 로 폭 ÷ 높이를 넣습니다 (`UIShaderEffect.cs` 39–43행).
- `step(0.001, _Progress)` — 0 이면 원래 uv 그대로 (300칸이라도 아주 살짝 흐려지는 것을 막음).

`PixelateTransition.cs` 30–38행

```csharp
DOTween.Sequence()
    .Append(material.DOFloat(1f, Progress, half).SetEase(Ease.InQuad))   // 거칠어짐
    .AppendCallback(() =>
    {
        currentIndex = (currentIndex + 1) % sprites.Length;
        image.sprite = sprites[currentIndex];                              // 가장 거칠 때 교체
    })
    .Append(material.DOFloat(0f, Progress, half).SetEase(Ease.OutQuad))   // 다시 선명
    .OnComplete(() => isTransitioning = false);
```

### 5. 언락 — 원 + 링 + 시퀀스 (0703)

`UnlockReveal.shader` 81–92행

```c
float3 locked = lerp(Gray(c.rgb).xxx, c.rgb, _LockedSaturation) * _LockedBrightness;   // 흑백 × 0.35

// 가로세로 비율을 보정한 중심 거리 (찌그러지지 않은 원)
float2 p = (uv - 0.5) * float2(_Aspect, 1.0);
float d = length(p);
float maxRadius = length(float2(_Aspect, 1.0)) * 0.5;      // 가운데 → 모서리 거리
float r = _Reveal * (maxRadius + _RingWidth);

float inside = 1.0 - smoothstep(r - _RingWidth * 0.3, r, d);
float ring = exp(-pow((d - r) / _RingWidth, 2.0)) * saturate(_Reveal * 30.0);

c.rgb = lerp(locked, c.rgb, inside) + _RingColor.rgb * ring * 0.9;
```

- `exp(-pow(x / 폭, 2))` = 가운데가 1, 멀어질수록 0 이 되는 **종 모양**(가우시안). 원 경계 `d = r` 에서 가장 밝은 링.
- 최대 반지름을 모서리까지 잡아 `_Reveal` 1 이면 구석까지 다 컬러가 됩니다.

`UnlockReveal.cs` 27–37행 — **애니메이션 → 셰이더 → 애니메이션** 을 시퀀스 하나로 (`docs/shader/37-unlock-reveal.md`)

```csharp
sequence = DOTween.Sequence();
sequence.Append(lockIcon.DOShakeRotation(0.4f, new Vector3(0f, 0f, 25f), 15, 0f));     // 1. 덜컹
sequence.Append(lockIcon.DOScale(1.6f, 0.3f).SetEase(Ease.OutQuad));                    // 2. 커지며
sequence.Join(lockGroup.DOFade(0f, 0.3f));                                               //    사라짐
sequence.Append(material.DOFloat(1f, Reveal, revealDuration).SetEase(Ease.OutCubic));   // 3. 컬러 퍼짐
sequence.Append(TargetRect.DOPunchScale(Vector3.one * 0.08f, 0.35f, 6, 0.8f));          // 4. 마무리
```

`material.DOFloat` 도 보통 트윈이라 `DOScale` 과 같은 시퀀스에 `Append` 됩니다.

### 6. 액체 — 셰이더가 용기까지 그림 (0704)

[그림: 둥근 용기 단면. 바깥 원(circle) − 안쪽 원(inner) = 테두리. 안쪽에 뒤 물결(어두운 파랑), 앞 물결(밝은 파랑), 수면 하이라이트, 왼쪽 위 유리 반사 호]

`LiquidFill.shader` 88–107행 요점

```c
float d = length(uv - 0.5);
float aa = fwidth(d) * 1.5;                                        // 크기와 상관없이 1~2픽셀로 부드럽게
float circle = 1.0 - smoothstep(0.5 - aa, 0.5, d);                 // 용기 바깥 원
float inner  = 1.0 - smoothstep(0.5 - _BorderWidth - aa, 0.5 - _BorderWidth, d);

float level = lerp(_BorderWidth, 1.0 - _BorderWidth, _Fill);       // 수위를 용기 안쪽 높이에 맞춤
float front = level + sin(uv.x * _WaveFreq + t) * _WaveAmp + sin(uv.x * _WaveFreq * 2.3 - t * 1.3) * _WaveAmp * 0.4;
float back  = level + sin(uv.x * _WaveFreq * 0.8 - t * 1.1 + 1.7) * _WaveAmp * 1.2;
```

- 스프라이트가 **없습니다** (Image 의 Source Image 비움). 원·테두리·물결을 모두 계산으로 그립니다.
- 위상이 다른 물결 두 겹(앞·뒤)으로 입체감을 냅니다.

`LiquidFillEffect.cs` 29–48행 — 수위와 출렁임은 **따로 트윈**

```csharp
fillTween?.Kill();
fillTween = DOTween.To(() => currentFill, x =>
    {
        currentFill = x;
        material.SetFloat(Fill, x);
        UpdateText();                                   // 퍼센트 글자도 함께
    }, targetFill, fillDuration)
    .SetEase(Ease.OutCubic);

sloshSequence?.Kill();
sloshSequence = DOTween.Sequence()
    .Append(material.DOFloat(sloshWaveAmp, WaveAmp, 0.15f))                // 0.06 으로 크게
    .Append(material.DOFloat(baseWaveAmp, WaveAmp, 1.4f).SetEase(Ease.OutQuad));  // 0.015 로 잔잔하게
```

> `_Fill` 과 `_WaveAmp` 는 **같은 머티리얼의 다른 프로퍼티**입니다. `material.DOKill()` 을 쓰면 둘 다 지워집니다. 그래서 트윈 변수를 따로 두고 `fillTween?.Kill()`, `sloshSequence?.Kill()` 로 하나씩 지웁니다.

### 7. 그라디언트 마스크 — 방향 + 부드러운 경계 (0705)

`GradientMaskFade.shader` 73–77행

```c
float t = ProjectUV(i.texcoord, AngleToDir(_Angle));                  // 진행 방향으로 0(시작)~1(끝)
float mask = saturate((_Progress * (1.0 + _Softness) - t) / _Softness);
c.a *= mask;
```

[그림: 가로 t 0~1. _Progress 0.5, _Softness 0.3 일 때 mask 가 1 → 0 으로 내려가는 경사. 경사 폭 = _Softness]

- `_Progress * (1 + _Softness)` — 디졸브의 `(1 + _EdgeWidth)` 와 같은 꾀. 경계 폭까지 포함해서 0 이면 **완전히** 숨고 1 이면 **완전히** 보입니다.
- `_Angle` 하나로 방향: 0 = 왼→오, 90 = 아래→위, 315 = 왼위→오아래. 버튼이 `SetAngle(float)` 로 바꿉니다 (`Build39_GradientMaskFade.cs` 22–24행).
- `ProjectUV` 는 6차시 셔이머와 같은 함수입니다.

목표: 0702 의 "가장 안 보일 때 바꾸기" 를 디졸브로. 다 타면 밤 풍경으로 바꾸고 다시 나타나게.

1. `Assets/01_Scripts/Shader` → 새 스크립트 `DissolveSwap` (**Create → Scripting → MonoBehaviour Script**, Unity 6 이전: **Create → C# Script**). 내용을 바꾼다.

   ```csharp
   using UnityEngine;
   using UnityEngine.UI;
   using DG.Tweening;

   // 디졸브로 사라짐 → 다 사라진 순간 다음 스프라이트로 교체 → 디졸브로 나타남
   public class DissolveSwap : UIShaderEffect
   {
       private const string DissolveAmount = "_DissolveAmount";

       [SerializeField] private Sprite[] sprites;
       [SerializeField] private float duration = 1.6f;   // 사라짐 + 나타남 전체

       private int currentIndex;
       private bool isTransitioning;

       private void Start()
       {
           material.SetFloat(DissolveAmount, 0f);
       }

       public void Next()
       {
           if (isTransitioning || sprites.Length == 0) return;
           isTransitioning = true;

           float half = duration * 0.5f;
           var image = (Image)targetGraphic;

           DOTween.Sequence()
               .Append(material.DOFloat(1f, DissolveAmount, half).SetEase(Ease.InQuad))
               .AppendCallback(() =>
               {
                   currentIndex = (currentIndex + 1) % sprites.Length;
                   image.sprite = sprites[currentIndex];
               })
               .Append(material.DOFloat(0f, DissolveAmount, half).SetEase(Ease.OutQuad))
               .OnComplete(() => isTransitioning = false);
       }
   }
   ```

## 정리

- 전환 셰이더 = **0~1 프로퍼티 하나** + 픽셀마다 "보일까" 를 계산. 스크립트는 `material.DOFloat` 한 줄.
- 디졸브: 노이즈 < 임계값 이면 지움. 범위를 `1 + 엣지 폭` 으로 늘려 끝에서 깨끗이 사라지게.
- 픽셀화: `floor(uv × 칸 수)` 로 칸 가운데 색만 읽기. `_Aspect` 로 정사각 칸. 가장 거칠 때 `AppendCallback` 으로 이미지 교체.
- 언락: `length` 로 원, 종 모양 `exp(-x²)` 로 링. 자물쇠(애니) → 컬러(셰이더) → 펀치(애니)를 한 시퀀스로.
- 액체: 스프라이트 없이 원·물결을 계산. 같은 머티리얼의 두 프로퍼티는 **트윈 변수를 따로** 두고 지운다.
- 마스크 페이드: `ProjectUV` 방향 위치 + `(1 + 부드러움)` 꾀. `_Angle` 하나로 방향.

## 과제

**과제 1. 나만의 전환 셰이더 한 줄** — 아래 중 하나를 골라 셰이더를 고친다. 프로퍼티를 하나 더하고(기본값은 원래 동작과 같게), 0 ↔ 1 로 바꿨을 때의 캡처 2장을 낸다.

| 픽셀화 칸을 가로로만 | `PixelateTransition.shader` 73행 `cellCount` | `float2(cells * _Aspect, lerp(cells, _MaxCells, _HorizontalOnly))` |

## 확인 질문

1. 디졸브에서 임계값을 `_DissolveAmount` 가 아니라 `_DissolveAmount * (1.0 + _EdgeWidth)` 로 쓴 까닭은?
   - **정답**: 엣지는 임계값 바로 위 `_EdgeWidth` 폭에 그려진다. 임계값이 1 까지만 가면 노이즈가 1 근처인 곳에 엣지가 남는다. 범위를 늘려야 1 일 때 엣지까지 완전히 사라진다.
2. 픽셀화 셰이더에 `_Aspect` 가 없으면 어떻게 보이는가?
   - **정답**: uv 는 가로·세로 모두 0~1 이라 같은 칸 수로 나누면, 가로로 긴 이미지에서 칸이 가로로 긴 직사각형이 된다. `_Aspect`(폭 ÷ 높이)를 가로 칸 수에 곱해 정사각형으로 맞춘다.
3. `LiquidFillEffect` 가 `material.DOKill()` 대신 `fillTween?.Kill()` 과 `sloshSequence?.Kill()` 을 따로 쓰는 까닭은?
   - **정답**: `_Fill` 과 `_WaveAmp` 가 같은 머티리얼의 다른 프로퍼티라, `material.DOKill()` 은 수위 트윈과 출렁임 트윈을 한꺼번에 지운다. 하나만 새로 시작하려면 트윈 변수를 따로 두고 하나씩 지워야 한다.

## 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 디졸브가 끝났는데 주황 점이 남음 | 내 셰이더에서 `(1 + _EdgeWidth)` 를 뺌 | 임계값 범위 늘리기 |
| 처음부터 주황 점이 보임 | `saturate(_DissolveAmount * 20.0)` 를 뺌 | 0 일 때 엣지 끄기 |
| **Directional** 칸이 안 보임 | Properties 줄을 안 넣음 / 변수 이름 다름 | 실습 2-2, 2-3. 대소문자까지 같게 |
| 셰이더가 분홍색, `undeclared identifier '_Directional'` | 변수 선언(`float _Directional;`)을 빠뜨림 | 실습 2-2 |
| 플레이 중 고친 값이 다른 이미지엔 안 걸림 | 사본은 이미지마다 따로 | 그 이미지의 `(Instance)` 를 고친다 |
| **Next Image** 가 안 생김 | Build Scene 을 안 돌림 / `DissolveSwap` 컴파일 오류 | Console 확인 후 메뉴 다시 |
| Console `InvalidCastException` (DissolveSwap) | 대상이 Image 가 아님 (RawImage·TMP) | Image 에 붙인다 |
| 이미지가 바뀌는 순간이 보임 | 사라지기 끝(1) 전에 교체 | 교체는 `AppendCallback` 에서, 첫 `Append` 뒤 |
| 픽셀 칸이 직사각형 | `ApplyAspect()` 를 안 부름 (내 스크립트) | `Start()` 에서 `ApplyAspect()` |
| 액체가 출렁이다 수위가 멈춤 | 내 코드에서 `material.DOKill()` 로 둘 다 지움 | 트윈 변수를 따로 |
| 마스크 방향이 반대 | 각도를 반대로 넣음 | 0 = 왼→오, 90 = 아래→위, 270 = 위→아래 |
