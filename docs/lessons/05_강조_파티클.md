## 학습 목표

1. 여러 트윈을 **시퀀스 하나**로 묶고 그 시퀀스 전체에 Ease·무한 Yoyo 를 거는 방법을 설명할 수 있다.

3. 기존 효과 스크립트를 부르는 작은 스크립트(`HoverPulse`, `CollectReward`)를 만들어 연출을 조합할 수 있다.

## 개념 설명

### 1. 용어

| 용어 | 한 줄 풀이 |
|---|---|
| 글로우 (Glow) | 물체 둘레에 번지는 빛 |
| `Outline` 컴포넌트 | UI 그림을 상하좌우로 살짝 밀어 한 번 더 그려 테두리처럼 보이게 하는 기본 컴포넌트. `effectDistance` = 미는 거리 |
| 9-Slice (Sliced) | 스프라이트를 9칸으로 나눠, 늘려도 모서리는 그대로 두는 방식 |
| 그리는 순서 | 같은 캔버스 안에서는 Hierarchy 위 → 아래 순서로 그린다. 아래 것이 위에 덮인다 |
| Render Mode | 캔버스를 화면에 그리는 방식. Overlay = 모든 것 위에 덮어 그림, Camera = 카메라 앞 평면에 놓고 그림 |
| Plane Distance | Camera 모드에서 캔버스를 카메라 앞 몇 미터에 둘지 |
| Order in Layer | 렌더러끼리 앞뒤 순서 번호. 클수록 나중에(위에) 그린다 |
| `Emit(n)` | 파티클 시스템이 지금 바로 n개를 뿜게 하는 함수 |

### 2. 시퀀스 하나에 무한 반복 걸기 (0501)

`GlowOutlinePulse.cs` 30–48행 (찾을 글자: `pulseSequence = DOTween.Sequence()`)

```csharp
SetGlowAlpha(glowMinAlpha);                          // 0.25 에서 시작
glowImage.rectTransform.localScale = Vector3.one;
if (outline != null) outline.effectDistance = outlineMinDistance;   // (1, -1)

// 글로우 밝기 + 크기 + 외곽선 두께를 함께 키웠다 줄였다 반복
pulseSequence = DOTween.Sequence();
pulseSequence.Append(glowImage.DOFade(glowMaxAlpha, duration));                 // → 0.9
pulseSequence.Join(glowImage.rectTransform.DOScale(glowMaxScale, duration));    // → 1.08
if (outline != null)
    pulseSequence.Join(DOTween.To(() => outline.effectDistance, v => outline.effectDistance = v, outlineMaxDistance, duration)); // → (4, -4)

pulseSequence.SetEase(Ease.InOutSine).SetLoops(-1, LoopType.Yoyo);
```

- 세 트윈에 따로 Loop 를 걸면 조금씩 어긋날 수 있습니다. **시퀀스 하나**에 걸면 늘 같이 움직입니다.
- Ease 도 시퀀스 전체에 겁니다(`pulseSequence.SetEase`). 안쪽 트윈은 기본 곡선 그대로 둡니다.
- `Outline.effectDistance` 는 DOTween 전용 함수가 없어서 3차시의 `DOTween.To` 를 씁니다.
- `OnEnable` 에서 시작(`playOnEnable` 이 켜져 있으면), `OnDisable` 에서 `Kill` — 2차시 펄스와 같은 규칙입니다.

| 필드 | 기본값 | 하는 일 |
|---|---|---|
| `duration` | 0.8 | 반 주기 (밝아지는 데 0.8, 어두워지는 데 0.8) |
| `glowMinAlpha` / `glowMaxAlpha` | 0.25 / 0.9 | 글로우 밝기 범위 |
| `glowMaxScale` | 1.08 | 글로우 최대 크기 |
| `outlineMinDistance` / `outlineMaxDistance` | (1, -1) / (4, -4) | 테두리 두께 범위 |
| `playOnEnable` | true | 켜지자마자 시작 |

**글로우 이미지** (`Build25_GlowOutlinePulse.cs` 15–26행): 빌더가 가장자리가 흐린 둥근 사각형 `SoftGlow.png` 를 코드로 그리고(테두리 60 짜리 9-Slice), 버튼보다 96 크게 깝니다. 9-Slice 라서 버튼 크기가 바뀌어도 모서리가 찌그러지지 않습니다.

**끌 때** (`StopPulse()`, 50–59행): 시퀀스를 지우고, 글로우 알파 0·크기 1·테두리 0 으로 0.25초에 돌립니다. `TogglePulse()` 는 `pulseSequence.IsActive()` 로 지금 도는지 봅니다.

### 3. 파티클을 UI 위에 (0502)

[그림: 표 두 칸. 왼쪽 Overlay — 화면 맨 앞 막(UI) 뒤에 파티클이 가려짐. 오른쪽 Camera — 카메라 앞 5m 평면에 UI, 그 앞(카메라 쪽)에 파티클, Order in Layer 10 > 0]

| 대상 | 설정 | 까닭 (`docs/animation/26-ui-particle.md`) |
|---|---|---|
| Canvas | **Screen Space - Camera**, Plane Distance 5 | Overlay 는 모든 것 위에 그려져서 파티클이 UI 뒤로 숨음 |
| Main Camera | Orthographic, Size 5.4 | 모든 데모 씬 공통 (`docs/scene-builder.md`) |
| ParticleSystem Renderer | **Order in Layer 10**, Material `ParticlesUnlit`(URP) | 캔버스(0)보다 크게 → UI 위에 그림 |
| ParticleSystem | Looping·Play On Awake 끔, Emission Rate 0, Simulation Space World | 스크립트의 `Emit()` 으로만 방출 |

`Build26_UIParticle.cs` 23–56행에 위 값과 함께 수명 0.6~1.1초, 속도 3~7, 크기 0.15~0.35, 중력 0.8, 구(반지름 0.2) 모양, 수명 끝으로 갈수록 작아지고 투명해지는 설정이 있습니다.

`UIParticleBurst.cs` 14–24행

```csharp
public void Play()
{
    // Screen Space - Camera 캔버스의 UI 는 실제 월드 좌표를 가지므로 그대로 파티클 위치로 사용 가능
    Vector3 pos = target.position;
    pos.z += zOffset;                          // -1: 캔버스보다 카메라 쪽으로
    burstParticle.transform.position = pos;
    burstParticle.Emit(burstCount);            // 40개를 지금 바로

    target.DOKill(true);
    target.DOPunchScale(Vector3.one * punchScale, 0.35f, 8, 0.8f);
}
```

- Camera 모드에서는 UI 도 월드 공간에 놓이므로 `target.position` 을 그대로 파티클 자리로 씁니다.
- `DOKill(true)` 의 `true` 는 "멈추기 전에 **끝 값으로 완료**" 입니다. 펀치 도중 또 눌러도 크기 1 에서 다시 튑니다.
- 파티클 시스템은 버튼 자식이 아니라 따로 있습니다. 시뮬레이션이 World 라 이미 나온 파티클은 버튼을 따라가지 않습니다.

| 필드 | 기본값 | 하는 일 |
|---|---|---|
| `burstCount` | 40 | 한 번에 뿜는 개수 |
| `punchScale` | 0.2 | 버튼 펀치 크기 |
| `zOffset` | -1 | 캔버스보다 카메라 쪽으로 띄우는 거리 |

   using UnityEngine.EventSystems;

   // 마우스가 올라와 있을 때만 GlowOutlinePulse 를 켠다

   public class HoverPulse : MonoBehaviour, IPointerEnterHandler, IPointerExitHandler

목표: **Collect!** 를 누르면 파티클 + 코인 숫자 +10 + 숫자 펀치가 함께 나오게 한다.

2. `Assets/01_Scripts/Animation` → 새 스크립트 `CollectReward`. 내용을 바꾼다.

   ```csharp
   using UnityEngine;
   using TMPro;
   using DG.Tweening;

   // 파티클 연출(UIParticleBurst)에 코인 숫자 증가 + 펀치를 더한다
   public class CollectReward : MonoBehaviour
   {
       [SerializeField] private UIParticleBurst burst;
       [SerializeField] private TMP_Text coinText;
       [SerializeField] private int reward = 10;

       private int coins;

       public void Collect()
       {
           burst.Play();

           coins += reward;
           coinText.text = coins.ToString();

           coinText.rectTransform.DOKill(true);
           coinText.rectTransform.DOPunchScale(Vector3.one * 0.3f, 0.3f, 1, 0.5f);
       }
   }
   ```

## 정리

- 함께 움직일 트윈은 **시퀀스 하나**에 넣고, 시퀀스에 `SetEase` + `SetLoops(-1, LoopType.Yoyo)`.
- 함수가 없는 값(`Outline.effectDistance`)은 `DOTween.To`. 끄는 함수(`StopPulse`)는 값을 0 으로 부드럽게 돌린다.
- 같은 캔버스 안에서는 Hierarchy **아래쪽이 위에** 그려진다. 글로우는 버튼보다 위(먼저)에 둔다.
- 파티클을 UI 위에: Canvas **Screen Space - Camera** + 파티클 **Order in Layer** 를 캔버스보다 크게 + `Emit(n)` 으로 원하는 때 방출.
- `DOKill(true)` 는 끝 값으로 완료하고 멈춘다 → 펀치 연타에 안전.

- 힌트: `CreateText("CoinText", root, new Vector2(0f, 220f), new Vector2(400f, 120f), "0", 80f, Color.white)`, `button.gameObject.AddComponent<CollectReward>()`, `Set(reward, "burst", burst)`, `Set(reward, "coinText", coinText)`, 그리고 61행 `OnClick(button, burst.Play);` 를 `OnClick(button, reward.Collect);` 로.
- 덤(선택): 0501 처럼 `CoinText` 뒤에 `SoftGlow` 글로우를 깔아 코인을 받을 때만 한 번 번쩍이게 한다 (`DOFade` 0.9 → 0).

## 확인 질문

1. 글로우 알파·크기·테두리 두께 트윈에 `SetLoops` 를 따로 걸지 않고 시퀀스에 한 번 거는 까닭은?
   - **정답**: 시퀀스 하나로 묶어 반복하면 세 값이 늘 같은 박자로 커졌다 작아진다. 따로 걸면 어긋날 수 있고 끄기도 번거롭다.
2. Canvas 를 Screen Space - Overlay 로 바꾸면 파티클이 안 보이는 까닭은?
   - **정답**: Overlay 캔버스는 카메라가 그린 모든 것 위에 덮어 그려진다. 파티클은 카메라가 그리므로 UI(배경 이미지 포함) 뒤로 숨는다.
3. `UIParticleBurst` 가 `Play()` 에서 `Emit(burstCount)` 를 쓰고, 파티클 시스템의 Looping·Play On Awake·Emission Rate 를 모두 끈 까닭은?
   - **정답**: 저절로 뿜지 않고, 버튼을 누른 순간에만 정한 개수를 바로 뿜게 하려고. 언제·몇 개를 스크립트가 정한다.

## 자주 막히는 곳

| 증상 | 원인 | 해결 |
|---|---|---|
| 인스펙터 값을 바꿨는데 펄스가 그대로 | 시퀀스는 `StartPulse()` 때 만든 값으로 돈다 | **Toggle Pulse** 두 번 |
| 글로우가 버튼을 덮음 | `Glow` 를 `PlayButton` 아래로 옮김 | Hierarchy 에서 `Glow` 를 위로 |
| 글로우 모서리가 찌그러짐 | Image Type 이 Simple | Image Type = **Sliced** |
| `HoverPulse` 를 붙였는데 늘 숨 쉼 | **Play On Enable** 이 켜져 있음 | 끄기 |
| 파티클이 아예 안 보임 | Canvas 가 Overlay / Order in Layer 가 0 이하 / Render Camera 가 빔 | Camera 모드, Order 10, Render Camera = `Main Camera` |
| 파티클이 분홍색 | Material 이 빠짐 | `ParticlesUnlit` (URP) 머티리얼 지정 |
| 파티클이 두 번 터짐 | On Click 에 `Play()` 와 `Collect()` 가 둘 다 있음 | `Play()` 줄 지우기 |
